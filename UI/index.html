Order Orchestrator — Console

UI mínima pra testar todos os endpoints. As respostas aparecem abaixo de cada formulário.

Autenticação

Criar usuário

POST/users
A `api_key` retornada é salva automaticamente no campo "API Key" acima.

Login (rotaciona API key)

POST/auth/login
Use se perdeu a chave. A chave anterior é invalidada e a nova fica salva no campo acima.

Enviar pedido (webhook autenticado)

POST/webhooks/orders
Usa o header X-Webhook-Secret — preencha o campo "Webhook Secret" no topo (valor da env WEBHOOK_SECRET).

Listar pedidos

GET/orders

Buscar pedido por ID

GET/orders/:id
Dica: clique em qualquer ID na lista de pedidos pra preencher.

Métricas da fila

GET/queue/metrics

Health check

GET/health
